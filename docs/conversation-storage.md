# 普通问答：完整历史与近期上下文

普通问答使用 Python 标准库 `sqlite3` 保存聊天记录，不增加第三方依赖。默认数据库为 `data/conversations/conversations.sqlite`；`CONVERSATION_DIR` 修改其所在目录。这个数据库保存已完成的问答，不保存代理执行位置，与专题研究的 LangGraph checkpoint 分开。

## 存储与模型上下文分别控制

- 数据库不再按 20 轮截断历史，持续保存每一轮已完成的问题、回答、追问建议与来源文本。
- `CHAT_CONTEXT_TURNS` 控制每次普通问答携带的最近轮数，默认 20，可设置为 1–100；CLI 和网页使用相同配置。
- `ConversationStore.load()` 读取完整历史，`load_recent()` 只在 SQL 中选取最近轮次；代理使用后者，并通过 `append_turn()` 保存新轮次。
- `save()` 兼容完整快照调用，只允许追加后缀或重复保存同一快照；拒绝用截短或改写的列表覆盖已有历史。

例如数据库已有 100 轮，设置 `CHAT_CONTEXT_TURNS=5` 后，第 101 轮只向模型附带第 96–100 轮，完成后数据库保存全部 101 轮。网页能分页读取更早记录；查看旧记录不会扩大模型上下文。

轮数限制用于控制输入规模，不是精确 token 上限；单轮文本长度、当前问题、证据、工具结果和系统提示也会消耗 token。未完成的当前轮仍不保存，也不支持从中断的工具调用或生成节点继续。

## 数据结构与一致性

`conversations` 保存会话 ID、标题、创建和更新时间、轮数及删除标记。`messages` 保存消息 ID、会话 ID、轮次序号、角色、正文和创建时间。每个完整轮次对应一条 user 和一条 assistant 消息。

每次操作使用独立 SQLite 连接；追加时以 `BEGIN IMMEDIATE` 取得写锁，在同一事务内提交两条消息和计数更新。失败时整轮回滚；并发追加不会通过“读出近期历史再覆盖”丢弃旧内容。默认连接锁等待上限为 30 秒。列表标题取首次保存的问题，显示最多 36 字符。

## 兼容旧 JSON

首次初始化存储时，将同目录尚未导入的有效 `{session_id}.json` 作为一个事务导入，保持顺序、会话 ID 和文件中的全部有效轮次，旧文件字节不变。时间采用旧文件修改时间。已有数据库会话不会被再次导入或被旧文件覆盖。

格式无效、条目不完整或无法读取的文件不做部分导入，原文件保留；会话列表返回 `migration_warnings`，网页提示未导入数量。修复旧文件后再次访问即可重试。迁移只能保留旧文件实际包含的记录，无法恢复此前已被 20 轮限制清除的内容。

删除操作移除数据库消息并保留删除标记，防止仍存在的 JSON 备份将其复活；旧文件不自动删除，网页确认框会说明这一点。已删除会话 ID 不能通过追加重新启用，请新建会话。该删除为数据库逻辑删除，不承诺清除 SQLite 空闲页或外部备份。

数据库、SQLite 日志文件及旧 JSON 都是本地私有数据。默认整个目录已被 Git 忽略；自定义目录时也需设置忽略规则。备份时请先停止服务，再一并保留数据库和旧文件。

## 分页 HTTP 接口

保留原路径和 `conversations`、`id`、`turns` 字段，增加分页元数据：

| 请求 | 返回 |
| --- | --- |
| `GET /api/conversations?limit=50&offset=0` | 会话列表按更新时间倒序，含 `turn_count`、`has_more`、`next_offset`、`migration_warnings` |
| `GET /api/conversations/{id}?limit=20` | 最近一页完整轮次，页内按时间正序，含 `total_turns`、`has_more`、`next_before` |
| `GET /api/conversations/{id}?limit=20&before=26` | 读取序号小于 26 的较早轮次；`before` 使用上页返回的游标 |
| `DELETE /api/conversations/{id}` | 沿用原确认和同源校验，删除数据库消息并保留旧 JSON 备份 |

`limit` 范围 1–100，`offset` 为非负整数，`before` 为正整数。无查询参数时默认返回 50 个会话或最近 20 轮，不再一次返回整份长历史。本地 Python 接口仍可读取完整历史。聊天记录游标不会因新轮次追加而向前偏移；会话列表使用 offset，列表更新时网页从第一页重新读取。

无效 ID 或分页参数返回 400；数据库或目录读写失败返回受控 500，不透传数据库异常正文。网页分别提供“加载更多会话”和“加载更早对话”，不会将旧页面内容加入模型请求。
