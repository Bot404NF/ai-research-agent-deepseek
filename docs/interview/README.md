# 面试材料导航

当前状态：工程演示可有条件使用，自动研究内容完整性未通过；[最新手测复核](../../eval/reports/manual_research_review_20261101.md)为最终内容验收依据。

面向 AI 应用／Agent 开发岗位，按以下四部分准备。当前状态和正式证据以注明日期的报告为准。

| 部分 | 阅读入口 | 用途 |
|---|---|---|
| 一、项目介绍与技术问答 | [面试准备](../interview-prep.md) | 一分钟介绍、推荐简历表述、架构取舍与常见追问 |
| 二、现场演示 | [5—8分钟演示](../interview-demo.md) | 准备环境、完整研究链路、恢复演示与备用结果 |
| 三、验证与证据 | [证据索引](evidence.md) | 根据表述定位原始结果、审核与测试记录 |
| 四、问题与改进方向 | [局限与下一步](limitations.md) | 解释失败、未采用决定及尚未完成的验证 |

先练习项目介绍，再按演示脚本操作；深入追问时打开证据和局限。历史架构及带日期的简历补充见[项目介绍与历史素材](../resume-project.md)。
