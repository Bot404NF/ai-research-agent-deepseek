# 本地最小诊断

`src/research_agent/observability/runtime.py`已接入问答、研究节点、模型、检索、工具、追问和保存阶段。它只记录请求ID、节点、包含关系的阶段耗时、逻辑调用次数、状态与实际usage，不记录正文、完整对话、工具参数、凭据或完整连接地址。

默认写到资料目录同级的`telemetry/日期.jsonl`，不提交到Git；设置`TELEMETRY_ENABLED=false`可关闭。写入失败不影响业务，节点暂停、工具错误和断流分别记录，不回显外部异常正文。

逻辑调用次数不等于SDK自动重试后的HTTP次数，后者未知时保持null。缺少usage也保持null；费用在绑定官方单价与日期的独立评测账本中计算。阶段耗时可能互相包含，不直接求和当作总耗时。

这是面向本地演示与排障的最小实现，没有集中监控、自动上传或后台清理；不继续引入监控平台。日志仅保留运行元数据，用户可在停止使用后按自身保留需求管理，程序不擅自删除历史记录。
