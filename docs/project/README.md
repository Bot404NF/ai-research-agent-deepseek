# 项目文档导航

当前状态：本地工程流程可用，自动研究内容完整性未通过；[最新手测复核](../../eval/reports/manual_research_review_20261101.md)为最终内容验收依据。

本项目是一个面向中文资料的个人开发研究助手，文档按以下四部分组织。当前状态和正式证据以注明日期的报告为准。

| 部分 | 阅读入口 | 用途 |
|---|---|---|
| 一、项目说明 | [项目说明](../project-guide.md) | 功能概览、架构取舍与常见问题 |
| 二、使用演示 | [5—8分钟演示](../demo.md) | 准备环境、完整研究链路、恢复演示与备用结果 |
| 三、验证记录 | [证据索引](evidence.md) | 根据表述定位原始结果、审核与测试记录 |
| 四、已知限制 | [局限与下一步](limitations.md) | 解释失败、未采用决定及尚未完成的验证 |

先阅读项目说明，再按使用演示操作；验证结果与限制分别查阅对应记录。历史架构与带日期的运行结果见[项目介绍与历史素材](../project-overview.md)。
