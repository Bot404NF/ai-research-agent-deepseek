# 问题与改进方向

以下区分已知问题和建议验证，建议不属于已实现能力。详细结论见[正式收口报告](../../eval/reports/interview_completion_20261101.md)。

| 已知问题 | 当前处理 | 下一步建议 |
|---|---|---|
| 最新现场研究仍漏掉古籍出版社整理本，人物与全志卷数归纳不清 | [手测失败留档](../../eval/reports/manual_research_review_20261101.md)，不判内容完整通过；初稿三卷／四卷保留来源差异 | 后续单独改进证据覆盖及阶段归纳，本轮不追加付费调优 |
| 检索候选引用支持未达到门槛，存在年号换算、OCR异字、版本及页种推测 | 保持 `GROUNDED_ANSWERS=false`，保留失败与退化分母 | 先逐项定位证据与表述错误，再单独做同口径对照，不反复生成挑最好结果 |
| 原始演示报告曾误判版本与时间阶段、误述获取日期 | [修订展示稿](../../eval/results/interview_demo_corrected_20261101.md)已针对性修正，旧报告保留；模型原始复验仍有页级称谓残留，修订稿另行辅助编辑 | 其他样本不据此标为修复；继续验证语义与原件，不宣称自动生成已完全解决 |
| 评分主要为AI辅助，题集已参与开发，未完成原件校勘 | 明确审核性质，不称为独立专家验收 | 建立未参与调优的验证样本并人工核对原件 |
| 恢复不能保证外部请求恰好一次 | 复用已保存成果，说明调用成功但未落盘时仍可能重复 | 针对该时间窗口验证重放及费用记录，不承诺零重复计费 |
| 性能数据属于本地固定样本，未证明高并发或生产SLA | 不默认启用未通过的本地追问；保留历史实验 | 有实际需求后再独立验证尾延迟、并发及部署边界 |
| 离线引文检查存在误报，模型API仍接收选中证据 | 诊断不自动改写原文，说明本地部署范围 | 将语义审核和字符诊断分开，按真实数据使用需求评估权限与隐私 |

不将混合检索平台、公网部署、完整索引备份恢复等尚未实现的方向写成项目成果。演示入口见[四部分导航](README.md)，可核验材料见[证据索引](evidence.md)。
