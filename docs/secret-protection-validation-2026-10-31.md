## 回归中发现并修复的遗漏

1. **URL 可能携带凭据。** API Key 的 repr 隐藏不能保护其他字段。合成哨兵测试发现连接 URL 会随 Settings 打印，因此同时隐藏两个连接 URL，并收紧连接状态展示。
2. **测试名也是输出。** 普通断言全部通过时，默认参数化 ID 仍可能把 Basic Authorization 样例写入 JUnit。产物扫描确实捕获该路径；已给样例显式指定安全场景 ID，重跑最终完整测试并重新扫描通过。
3. **未知异常不能按类型直接信任。** 原有部分 ValueError/RuntimeError 会转成用户错误正文。现在只公开应用自身构造的 PublicInputError，其他错误使用安全元数据，保留原 JSON/SSE 字段。

## 适用范围与后续约束

扫描是启发式检测，不能发现所有凭据格式、编码、拼接和隐藏方式；公开示例值的明确白名单也不表示弱口令安全。测试网络限制不是操作系统级隔离，不能约束恶意插件或任意外部程序。repr 隐藏也不保护 asdict、直接字段读取或手动调试打印。

安全测试和扫描通过不代表全部用户数据安全问题已经解决。本轮不实施账户认证、资料权限、磁盘加密、保留期限或完整删除策略。运行命令、接口行为和泄露处理约定见 [防泄露说明](secret-protection.md)。
