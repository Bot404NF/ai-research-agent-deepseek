# 知研网页设计规范：深色对话界面

- 版本：1.1
- 制定日期：2026-10-30
- 状态：深色界面与模式切换已实现，逐项验收结果见文末。
- 适用范围：知研本地网页的问答、研究、资料导入与历史记录。

本文是实现与验收的依据，示意图描述设计意图，实际验证范围见文末。网页现默认进入问答，顶部胶囊切换用于进入问答或研究。

## 1. 目标与边界

借鉴 ChatGPT 的简洁侧边栏、居中阅读区和底部输入框，形成以中文阅读和来源核对为中心的深色界面；保留“知研”品牌，不复制其他产品标识。视觉重点依次为用户问题、回答正文、引用来源和辅助操作。

本期按示意图实现深色界面和顶部“问答 / 研究”切换。实现沿用现有 HTML、CSS、JavaScript 与 HTTP 接口，不引入前端框架，不变更模型、向量库结构或检索排序；联网许可按后续用户要求改为按需问询并持久化等待状态。保留仓库已有修改，不通过界面改版迁移或清空数据。

仅设计深色主题，不增加主题切换、登录、模型选择、会话搜索、附件分析、停止问答生成、重新生成等尚无对应功能的入口。原始会话 ID、索引集合名和向量模型等实现细节不出现在主要操作区。

## 2. 信息架构与布局

### 2.1 全局外壳

| 区域 | 规格与行为 |
| --- | --- |
| 桌面侧栏 | 展开宽 260px，固定于左侧；顶部为“知研”、折叠按钮、“新建对话” |
| 侧栏分区 | 从上到下固定为 **资料库 → 研究任务 → 历史会话**，切换工作区不改变顺序，也不隐藏其他分区 |
| 侧栏滚动 | 顶部与底部固定，中间三个分区共用纵向滚动区，避免三个列表各自形成滚动容器 |
| 侧栏底部 | 本地资料库连接状态，使用图标与文字表达，详细技术信息放在辅助说明中 |
| 主区顶栏 | 桌面高 76px，移动高 68px；主区正中展示“问答 / 研究”胶囊切换，两侧保留导航空间，不因模式变化偏移 |
| 问答正文 | 内容宽度不超过 768px，水平居中；左右留白各至少 24px |
| 研究正文 | 内容宽度不超过 960px，水平居中，与问答共享顶栏和侧栏 |
| 滚动 | 对话或研究正文独立滚动；顶栏与底部输入区不被正文挤出视口 |
| 输入区 | 与问答正文同宽，底部预留 16px 与安全区；正文底部预留输入区实际高度，避免遮挡最后一条消息 |

打开页面默认进入问答：有已保存的当前会话时恢复该会话，否则进入空白首页。已记住的研究任务不自动抢占默认入口；点击侧栏研究任务或顶部“研究”模式进入研究工作区。工作区切换不取消正在运行的研究任务。

桌面折叠后侧栏宽 56px，保留展开、新建对话以及按原顺序排列的资料库、研究任务、历史会话分区图标。点击分区图标展开侧栏并定位对应分区，不触发数据操作；图标提供中文辅助名称。折叠状态仅为布局状态，不改变当前会话或任务。

## 3. 视觉参数

### 3.1 颜色变量

后续 CSS 统一使用下列变量，不在不同工作区另造一套颜色。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg-main` | `#212121` | 主背景、助手正文背景 |
| `--bg-sidebar` | `#171717` | 侧栏、移动抽屉 |
| `--bg-surface` | `#303030` | 输入框、用户气泡、弹窗、代码背景 |
| `--bg-hover` | `#3A3A3A` | 可操作元素悬停 |
| `--text-primary` | `#ECECEC` | 正文、主要标题、已选条目 |
| `--text-secondary` | `#A8A8A8` | 导航分组名、日期、提示与占位文本 |
| `--border-default` | `#454545` | 分隔线、输入框与表格边线 |
| `--button-primary-bg` | `#ECECEC` | 主操作按钮背景 |
| `--button-primary-text` | `#212121` | 主操作按钮文字和图标 |
| `--focus-ring` | `#B4D4FF` | 键盘焦点轮廓 |
| `--link` | `#B4D4FF` | 可点击链接，正文链接同时加下划线 |
| `--status-success` | `#8FD3A8` | 已连接、成功 |
| `--status-warning` | `#EAC77A` | 等待、授权提示 |
| `--status-error` | `#FFB4AB` | 错误、危险操作文字 |

普通正文及必要提示文字与背景对比度至少 4.5:1；控件关键边界及焦点与相邻背景至少 3:1。装饰分隔线可使用默认边框色，但不能单独承担输入控件识别或焦点提示。禁用操作使用禁用语义和对应说明，不仅依靠降低透明度；错误、连接和任务状态不能仅通过颜色表达。

### 3.2 字体、尺寸与动效

| 项目 | 规格 |
| --- | --- |
| 字体 | 系统无衬线字体，优先 `system-ui`、`PingFang SC`、`Microsoft YaHei`；不依赖远程字体 |
| 正文 | 16px，行高 1.75，常规字重 400 |
| 导航与按钮 | 14px，行高 1.5；主要按钮字重 600 |
| 辅助信息 | 最小 12px，行高 1.5 |
| 标题 | 页面标题 20px；回答内标题 24/20/18px；首页欢迎语桌面 28px、移动 24px |
| 间距 | 基础单位 4px，常用 8、12、16、24、32px；段落下间距 16px |
| 圆角 | 列表项与次要按钮 8px；用户气泡 16px；输入框 24px；弹窗 16px |
| 图标 | 统一线性图标，默认 20px，描边 1.75px，使用本地内联 SVG；不得用含义不明的字符或表情替代操作图标 |
| 输入框 | 初始最小高度 56px，文本自动增高至 192px，超出后仅文本区滚动 |
| 焦点 | 2px 实线轮廓、2px 外偏移，不通过去掉 outline 隐藏键盘焦点 |
| 动效 | 悬停与展开过渡 120–180ms；遵守 `prefers-reduced-motion`，禁用非必要动效 |

取消蓝紫渐变、大面积彩色状态背景和多层投影。层级优先用留白、背景和字重表达；遮罩使用半透明黑色，弹窗高于遮罩，遮罩高于页面与输入区。

## 4. 组件交互与状态

### 4.1 侧栏、资料与历史

研究任务分区展示历史任务及状态，点击任务打开详情；新建研究统一使用侧栏“新建对话”重置后切换“研究”模式。研究正文不再重复放置“新建研究”按钮或历史任务下拉框；移动端通过侧栏抽屉访问相同入口。

研究任务条目与历史会话共用垃圾桶样式，桌面悬停或键盘聚焦时显示，移动端直接可见。点击后打开确认弹窗，默认聚焦取消；明确删除该任务的计划、证据、成果、报告及恢复记录，不影响资料库和其他任务。确认期间禁止重复提交，失败保留弹窗并支持重试；运行中的任务需先取消并等待停止。删除当前任务后研究区回到新建页面，删除其他任务保留当前草稿与阅读状态。

- 资料库条目仅展示名称，不展示展开箭头，不使用折叠目录控件。点击名称不展开目录或文件、不改变检索范围、不呈现“已选择资料库”状态。移除“从左侧选择主题”等不符合此行为的提示。
- “导入资料”打开新建目录弹窗。保留 TXT、Markdown、PDF、多文件、文件夹和文件拖放；单次上传总量不超过现有 100 MB 限制。只提供“新建目录并导入”，不出现“添加到已有目录”。
- 导入区展示目录名称、已选文件、文件总量与进度文字；强调“导入后可供问答检索”，不在主要说明中暴露向量模型或集合名。扫描版 PDF 暂不支持 OCR 的限制保留为辅助提示。
- 研究任务显示名称与文本状态，点击恢复对应研究；历史会话显示标题并恢复问答。各自的当前条目使用背景与可访问状态标识，标题过长省略，不能把任务与普通会话混为一个列表。
- 删除数据库或会话仍使用已有独立操作。桌面悬停或键盘聚焦时显示操作，触屏始终可见；数据库条目旁的删除按钮不得与名称点击区域混用。
- 加载失败显示对应分区的失败信息和重试动作，不显示为空记录；某个分区失败不遮挡其他分区。

### 4.2 输入、回答与来源

- Enter 提交非空问题，Shift + Enter 换行；中文输入法组合期间的 Enter 只确认候选字，检查 `isComposing` 与组合输入状态，不发送问题。
- 空输入与发送期间禁用发送按钮；图标按钮保留“发送”的辅助名称。流式输出显示“正在回答”及低干扰进度标识，不用停止图标替代禁用发送按钮。
- 失败时显示可理解的错误，保留已展示内容及未成功发送的问题，便于复制或再次编辑；不自动重复付费请求。
- 问答按轮询问联网许可；研究在资料不足或需核对时效时暂停并询问本任务许可，提供“允许本次研究联网”和“仅用资料库继续”，未经同意不联网。检索失败不能伪装成资料为空并触发自动搜索。
- 每轮回答下方默认折叠“查看来源 · N 条”。展开后仅按“资料库”和“网络”两类组织，分类内保留本轮原始引用编号，不因展示顺序变化重新编号。无结果类别不显示，两类都为空则不创建空来源区。
- 资料库来源保留 `[S#]`、文件路径、可用页码及相关性；网络来源保留 `[W#]`、标题、网站、发布机构、发布日期、获取日期、适用范围和网址，缺失信息沿用现有未注明提示。文本按安全方式展示，不执行来源中的 HTML。
- 来源区中每条记录分别排版，长路径与网址允许断行；网络链接有清晰的交互样式。本地路径保持来源文字，不凭空提供浏览器无法访问的打开文件动作。
- 历史任务和会话中已有 `[N#]`、`[O#]` 及原回答文字不被改写；需要归类其来源时按资料库处理，不重新产生“新增／旧资料”分组。
- 完成回答后，已有追问建议显示为轻量按钮；点击沿用现有提问行为，不自动授予联网许可。

### 4.3 弹窗与确认

导入弹窗最大宽 560px，删除确认最大宽 420px，移动端左右至少留 16px。高度不超过动态视口扣除 32px 的空间，内容较长时弹窗内部滚动，主要动作始终可达。

打开时记住触发元素，将焦点移至首个表单字段或安全操作；使用对话框语义、可访问标题及说明。Tab 和 Shift + Tab 的焦点限制在弹窗内，背景不可交互。普通状态支持关闭按钮、Escape 与遮罩关闭，关闭后焦点返回触发元素，触发元素已移除时返回所在分区的入口。

删除弹窗默认聚焦“取消”，明确目标名称、原始文件、补充文件与索引的实际删除范围及不可恢复性。必须再次点击“删除”才发起请求，不能因 Enter 打开弹窗而连续确认。删除请求提交后禁用重复操作，返回前不关闭弹窗；失败保留说明并允许重试。

导入期间禁止重复提交。关闭弹窗不代表取消已开始的上传或索引请求；请求期间 Escape、遮罩和关闭按钮不退出，说明“正在导入，请等待当前操作完成”。失败显示实际错误与已完成进度，不自动重复创建目录；其余操作可在请求结束后恢复。关闭弹窗不删除已创建目录或已上传文件。
