# 评测数据集

当前唯一主评测集为`unified.json`：100题统一编号T001–T100，不按新老分组；65道单来源、17道组合、18道无答案或强答诱导。问题、参考答案和原文锚点统一保存。该集用于开发回归及质量验收，不是独立留出集。标准与运行见[统一验收方案](../experiments/quality_target.md)。`build_unified.py`校验来源摘要及锚点后首次构建，拒绝覆盖现有主题集。

`questions.json` 为开发集；`holdout_questions.json` 和 `holdout_manifest.json` 为历史冻结题集及摘要清单。文件从 `eval/` 原样迁入，保持内容和 SHA-256 不变。

以下历史文件保留供追溯，日常入口统一使用主题集。部分题目已被查看并参与优化，不能声称独立留出成绩。合成无答案题不能代表真实无答案检测能力。
