# 第四周：默认问答接入、性能与成本（运行前指标）

用户已授权包含默认业务接入，真实API预算上限人民币10元；不提交、不推送、不重建索引。日期2026-10-31。

## 固定方案

- 统一100题不改题、不删失败、不调整评分。真实执行`stream_answer_turn`，覆盖确定性检索、工具消息、流式回答、追问和历史写入；隔离会话，不写个人会话。禁用联网和导入工具的实际执行。
- 两组均接入来源范围/内容选择与证据约束：baseline使用模型追问，candidate使用本地操作型追问。唯一性能变量是省去追问模型调用，最终答案仍由相同模型生成，不裁剪证据、不降低输出上限。不把质量候选接入的收益归因于性能变量。
- 两组同一Flash、非思考、温度0、每请求最多4096输出Token、无自动重试，按题交替组顺序。每题每组一次，共200次真实业务轮次；工具循环最多沿用原6次上限。按本轮真实业务比较，不借历史生成耗时拼接端到端数据。
- 首次完整业务调用作为冷/首次调用样本单列；随后100题为预热数据。记录从调用开始到第一个非空回答token、最后一个回答token、建议/来源及会话保存结束的耗时。主指标为轮次完成P95，最后回答token耗时另报，避免把建议阶段节省冒充正文生成提速。
- 全200份回答按参考答案、实际证据、原回答做AI审核；解析失败保留usage、未评分保留分母，额外审核不重生成作答。全量失败/退化及固定随机抽样20份通过样本由Codex复查，区分AI与真人。

## 预设门槛

| 指标 | 门槛 |
|---|---|
| 完整正确/正题引用/拒答/组合题 | candidate通过数分别不低于同轮baseline；且至少74/82、80/82、18/18、16/17（上轮质量候选已观测水平） |
| 轮次完成时间 | 预热P95降低≥20%，P50不退化；首正文Token及最后正文Token分开，不设未经测量的绝对秒数目标 |
| 回答总估算成本 | 同一人民币空闲单价重算，100题包含答案、工具循环、建议、失败预留，降低≥15%；另报实际时段估算费用 |
| 稳定性 | 失败、超时、截断数均不增加，候选100轮完整；业务权限、历史、来源标签、增量集合及多轮回归通过 |
| 采用 | 质量与稳定性为硬门槛；时间或成本至少一个达到、另一个不退化才启用；失败保留原默认并报告 |

P95最近秩法，100样本仅作开发实验，不能证明线上SLA；单次生成有随机性，逐题退化ID必须列出。冷启动涵盖首次模型初始化/检索，不包含Python模块导入；不冒充完整进程冷启动。网页传输/浏览器渲染、并发和完整研究图不计入本轮主性能声明，HTTP契约与研究流程仅做兼容回归。

## 费用和边界

官网中文价格页：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ ，获取日期2026-10-31，发布机构DeepSeek，网页未标单独发布日期。`deepseek-flash`对应DeepSeek-V4.1-Flash-1017。人民币每百万Token：空闲命中0.02、未命中1、输出4；高峰0.04、2、8。高峰为北京时间工作日9–12、14–18，中国法定节假日除外；本轮周末固定空闲，如跨日则按请求时间记录。后续工作日节假日状态不明时用高峰保守估算，不自行认定优惠。

预算使用独立持久账本：每次请求前预留0.5元，限制序列化输入和工具定义在100KB以内、输出≤4096、无重试；预留按高峰及额外包装裕量保守覆盖。成功且usage完整时按高峰价格释放差额，失败或usage缺失保留全部预留并停止后续付费调用；每次实际发出前落盘。账本总承诺不超过10元，审核和预热同样计入。金额为公开价格估算而非账户账单；审核、回答费用分别报告。预算耗尽保留未完成项，不自动追加预算。

不新增回答缓存、证据裁剪或并发；本地追问只提出核对原文、缺证、版本等操作，不声称证据存在额外事实。保留`FOLLOWUP_MODE=model`和`GROUNDED_ANSWERS=false`回退配置。默认启用必须由上述结果决定。

## 交接后冻结说明（第二次运行前）

并行接入已由本聊天统一负责。唯一业务入口为`retrieve_library`，`retrieve_business`只作兼容转发；开关false真实回退到原整题检索预算，新提示词只使用一份共用约束。CLI、网页、研究节点共用同一检索入口。范围匹配补充TXT/PDF，显式书名无候选时不使用其他书替代。增量目录扩展门槛沿用最终top_k而非12条候选预算。

首次第四周运行由用户暂停，18题完整对照及第19题部分结果保留，不用于最终指标。未确认请求继续按0.5元占用预算；交接的一次CLI回答未保存usage，额外占用0.5元费用准备。这两项均未当作实际已知费用，也未清零；后续新运行允许在保留费用占用的条件下继续。新运行重新执行全100题，不挑选旧结果；源码前后摘要、实际提示词与模型参数写入新结果。HTTP冒烟通过专门包装器计入同一预算，不直接重跑未接入账本的旧冒烟入口。

抽查已发现自动审核漏判页面身份和额外公元年份，两组引用均仅78/82，未满足80/82的质量底线，不能采用。下一次完整运行前收紧共用提示词：只答所问字段及必要异说，不推断页种、不自行换算年号；恢复“未匹配文件名时仍可由其他书著录”的全库回退。两组同用修正后的质量路径，性能变量仍只有追问方式；不改题集或门槛，不将不同运行回答拼成一套。最终报告仅按统一100题统计，不按暂停前后分题或加标签。

## 尾延迟复测规则（任何新增重复测量前固定）

完整运行出现P50及成本改善但P95退化时，不改门槛、不据此启用。先完成该轮200份质量审核；仅当质量通过时，才在预算内追加两轮相同代码、相同100题的业务测量，最多共3轮/每组300样本。三轮顺序完成、全部样本统一计算分位数与费用，禁止挑最好的一轮、删慢样本或只取成功配对；失败数及代码漂移仍为硬门槛。若预算不足、任一轮未完成或代码变化，不能按完整300样本验收。语义分数以完整100题审核为准，重复轮用于性能稳定性测量，不冒称300道独立问题或300道质量验收。
