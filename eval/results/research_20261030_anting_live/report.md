# 《安亭志》编纂、版本与史料价值研究报告

## 主要结论

- 清代《安亭志》为陈树德编纂，孙岱参与合辑。陈树德受瞿中溶之邀，于嘉庆十二年初编纂，经近半年完稿，成书于嘉庆十二年（1807年）七月，嘉庆十三年（1808年）刊刻。[O2][O4]
- 现代整理本在现有证据中出现两个版本：上海古籍出版社2003年7月版（朱瑞熙标点）与上海社会科学院出版社2003年版（王健标点），两者在标点者、丛书名、出版社上存在明显分歧，已分别呈现，未合并。[O6][O7]
- 清嘉庆《安亭志》为20卷，体例被后人赞为“分并清晰，体例尽善”，艺文卷收集较齐全。史料价值方面，证据提供了保存两宋至明清散佚文献、补归有光集之缺、保存严衍佚文、补钱大昕集之缺等具体例证。[O9][O12]
- 关于“使用局限”，现有证据中未发现直接、明确记载，属研究缺口，不能凭常识补足。[O9][O12]


## 分题分析

### 一、清代编纂者及成书刊刻沿革

**编纂者**

- 陈树德，乾隆、嘉庆间安亭人，字以诵，又字槐江，自称槐江学人，国子生，居安亭镇。生卒年不详。[O2][O4]
- 孙岱，陈树德外甥，曾“以留心文献为己任，搜存补亡”，完成《人物志》初稿，后病故。[O2][O4]
- 陈树德受金石学家瞿中溶之邀，于嘉庆十二年初负责编纂安亭志。[O2]

**成书过程**

- 据陈树德自跋：康熙、雍正年间，夏澄（著有《濠梁诗草》）、卫楫曾“有意著录”，但“属草未竟，旋就散轶”。[O2]
- 孙岱计划编写《安亭江志》，经五年努力完成《人物志》初稿，未竟而卒。[O2]
- 嘉庆十二年初，陈树德受瞿中溶之邀编纂，经近半年完稿，随即付梓。[O2]
- 成书时间：嘉庆十二年（1807年）七月。[O2]

**刊刻沿革**

- 清嘉庆十三年（1808年）刻本，上海图书馆藏。[O4]
- 嘉定知县吴桓为该志撰序，署时为嘉庆十三年五月。证据据此推断该志最后问世当在同年五月稍后，此为推断性表述，非直接记载。[O2]
- 1916年油印清嘉庆十三年本，甘肃图书馆藏。油印本的具体出版者、地点、册数，证据未提供。[O4]
- 1937年吴廷铨仿宋铅印本，2册；重印本增有里人吴廷铨重印《安亭志》跋。[O4]
- 南京博物院藏有昆山图书馆抄本。[O4]
- 上海图书馆另藏：清乾隆三十七年（1772年）孙岱手稿本1册（不分卷），书名《安亭江志稿》；同年陈树德手稿本2册（不分卷），书名《安亭志稿》。[O4]

**卷次与体例**

- 全志共20卷，卷首有《安亭镇图》、凡例10则、嘉庆十三年嘉定知县吴桓序；卷末有陈树德自撰跋。[O4]
- 卷目（据O4）：卷一缘起、坊巷、津梁、营汛；卷二水道（附水利）；卷三风俗（附物产）、田赋（附图圩）；卷四小学、选举；卷五至卷八艺文·文编；卷九至卷十一艺文·诗编；卷十二艺文·书目、碑目；卷十三古迹（附第宅、园林）；卷十四祠庙（附亭观）；卷十五冢墓；卷十六至卷十八人物；卷十九列女；卷二十杂识。[O4]
- 另一来源将卷目概括为十七目：沿革、缘起、坊巷、津梁、营汛、水道、风俗、田赋、小学、选举、艺文、古迹、祠庙、冢墓、人物、列女、杂识。[O2]
- 卷一是否含“沿革”目，O4、O2、O12记载不一致，已分别呈现，未合并。[O2][O4][O12]

**本分题待核实事项**

- 孙岱所撰《人物志》卷数存在分歧：O2称“四卷”，O4称“《安亭人物志稿》3卷，陈则增补17卷，合为20卷”。两处记载不一致，需分别引用，不能合并。[O2][O4]
- 孙岱手稿本与陈树德手稿本均署“清乾隆三十七年（1772年）”，而正文成书署嘉庆十二年（1807年），两者时间关系及手稿本性质在证据中未作解释。[O2][O4]
- 夏澄、卫楫所撰未竟稿的存佚情况，证据未提供。[O2]

### 三、内容体例、史料价值及使用局限

**内容体例**

清嘉庆《安亭志》为20卷，卷目结构如下[O12]：

- 卷一：沿革、缘起、坊巷、津梁、营汛5目
- 卷二：水道、水利2目
- 卷三：风俗、土产、田赋、都图4目
- 卷四：小学、选举2目
- 卷五至卷八：艺文（一）至（四）文编，其中卷七为议、书，卷八为传、事略、跋、疏
- 卷九至卷十一：艺文（五）至（七）诗编
- 卷十二：艺文（八）书目、碑（石刻）目
- 卷十三：古迹、第宅、园亭3目
- 卷十四：祠庙、寺观2目
- 卷十五：冢墓
- 卷十六至卷十八：人物（一）至（三）
- 卷十九：烈女
- 卷二十：杂识

卷首列整理说明、安亭志序、凡例、安亭镇图；卷尾列排跋、重印《安亭志》跋。[O12]

体例评价方面，后人赞其“分并清晰，体例尽善”。该志内容较丰，“尤其是艺文卷，于文、记、书、传、事略、跋、疏、诗、书目、碑刻等收集比较齐全”。[O12]但此评价出自何人、何书，证据未注明，需核实。[O12]

**史料价值的具体证据**

据上海地方志资料集所收《安亭志》整理本相关记载，该志“取材得当、考订精审、内容详备”，记述了安亭的历史沿革、经济发展状况、社会人文习俗等，具有较高的历史文献价值。[O9]具体例证包括：

1. **保存两宋至明清散佚文献**：该志保存了两宋至明、清历朝有关安亭的文献，其中许多诗文实际已经散失，“即使断简残编，也弥足珍贵”。[O9]具体包括：
   - 宋钦宗靖康元年（1126）范浩撰永怀禅寺《诸天阁记》
   - 宋理宗朝礼部颁给菩提禅寺的“指挥”
   - 宋度宗咸淳二年（1266）陈鉴撰《宋太安人徐氏墓志铭》
   - 元顺帝至正七年（1347）刘景元撰重修永怀禅寺记
   - 至正九年正印撰《实际川禅师影堂逸事》
   - 元末王原杰撰《平江路照磨王峇墓志铭》

   以上“皆为其他各书失载，足以弥补今人所编《全宋文》和《全元文》之缺”。[O9]

2. **补归有光集之缺**：该志所收归有光撰《沈才备墓志铭》（卷十五）、《下第归安亭寄友人》诗（卷九），均为上海古籍出版社1981年周本淳点校《震川先生集》所漏收。[O9]

3. **保存严衍佚文**：明代史学家严衍精通《资治通鉴》，今存《通鉴补正略》等，但没有文集传世，该志收录其所撰《张茂仁传》（卷八）。[O9]

4. **补钱大昕集之缺**：清代学者钱大昕虽已有全集整理出版并辑补遗文，但失收仍多。该志收其《募修圆元道院疏引》（卷八）、《浙江分巡宁绍台海防兵备道印宪曾墓志铭》、《国学生陈国祥墓志铭》（卷十五）、《过家江邨旧居》诗（卷十一），“皆为其诗文集所得读者留意”。[O9]

**使用局限**

现有证据中，未发现对《安亭志》使用局限的直接、明确记载。O9仅从正面肯定其价值，未提及局限；O12亦未涉及局限问题。此为研究缺口，不能凭常识推断其局限。[O9][O12]

**本分题待核实事项**

- 使用局限无证据支持：现有证据均未提供直接记载。[O9][O12]
- 体例评价的出处与语境：O12称后人赞其“分并清晰，体例尽善”，但未注明此评价出自何人、何书。[O12]
- O10所记为1990年上海社会科学院出版社出版的《安亭志》（上海市嘉定县安亭镇修志领导小组编，陆成基主编），属当代新编镇志，其体例为建置、地理、党政群团等十七类，与清嘉庆《安亭志》20卷体例完全不同。两者不可混同。本问题所问应明确指向清嘉庆《安亭志》。[O10][O12]
- O9所据版本未注明：O9引用《安亭志》卷次（卷八、卷九、卷十一、卷十五），但未注明所据为清刻本、民国铅印本还是现代整理本。[O9]

### 证据缺口

1. **孙岱《人物志》卷数**：O2称“四卷”，O4称“3卷”，证据冲突且无第三方证据可裁决。[O2][O4]

7. **夏澄、卫楫未竟稿存佚**：证据未提供。[O2]

- 嘉定知县吴桓为该志撰序，署时为嘉庆十三年五月，据此推断该志最后问世当在同年五月稍后。[O2]（此为推断性表述，非直接记载）
- 1916年油印清嘉庆十三年本，甘肃图书馆藏。[O4]

- 南京博物院藏有昆山图书馆抄本。[O4]
- 上海图书馆另藏：清乾隆三十七年（1772年）孙岱手稿本1册（不分卷），书名《安亭江志稿》；同年陈树德手稿本2册（不分卷），书名《安亭志稿》。[O4]

### 卷次与体例

- 全志共20卷，卷首有《安亭镇图》、凡例10则、嘉庆十三年嘉定知县吴桓序；卷末有陈树德自撰跋。[O4]

## 子问题三：内容体例、史料价值及使用局限

### 一、内容体例

清嘉庆《安亭志》为20卷，卷目结构如下[O12]：

- 卷一：沿革、缘起、坊巷、津梁、营汛5目
- 卷二：水道、水利2目
- 卷三：风俗、土产、田赋、都图4目
- 卷四：小学、选举2目
- 卷五至卷八：艺文（一）至（四）文编，其中卷七为议、书，卷八为传、事略、跋、疏
- 卷九至卷十一：艺文（五）至（七）诗编
- 卷十二：艺文（八）书目、碑（石刻）目
- 卷十三：古迹、第宅、园亭3目
- 卷十四：祠庙、寺观2目
- 卷十五：冢墓
- 卷十六至卷十八：人物（一）至（三）
- 卷十九：烈女
- 卷二十：杂识

卷首列整理说明、安亭志序、凡例、安亭镇图；卷尾列排跋、重印《安亭志》跋[O12]。

体例评价方面，后人赞其“分并清晰，体例尽善”[O12]。该志内容较丰，“尤其是艺文卷，于文、记、书、传、事略、跋、疏、诗、书目、碑刻等收集比较齐全”[O12]。

### 二、史料价值的具体证据

据上海地方志资料集所收《安亭志》整理本相关记载，该志“取材得当、考订精审、内容详备”，记述了安亭的历史沿革、经济发展状况、社会人文习俗等，具有较高的历史文献价值[O9]。具体例证包括：

1. **保存两宋至明清散佚文献**：该志保存了两宋至明、清历朝有关安亭的文献，其中许多诗文实际已经散失，“即使断简残编，也弥足珍贵”[O9]。具体包括：
   - 宋钦宗靖康元年（1126）范浩撰永怀禅寺《诸天阁记》
   - 宋理宗朝礼部颁给菩提禅寺的“指挥”
   - 宋度宗咸淳二年（1266）陈鉴撰《宋太安人徐氏墓志铭》
   - 元顺帝至正七年（1347）刘景元撰重修永怀禅寺记
   - 至正九年正印撰《实际川禅师影堂逸事》
   - 元末王原杰撰《平江路照磨王峇墓志铭》

   以上“皆为其他各书失载，足以弥补今人所编《全宋文》和《全元文》之缺”[O9]。

2. **补归有光集之缺**：该志所收归有光撰《沈才备墓志铭》（卷十五）、《下第归安亭寄友人》诗（卷九），均为上海古籍出版社1981年周本淳点校《震川先生集》所漏收[O9]。

3. **保存严衍佚文**：明代史学家严衍精通《资治通鉴》，今存《通鉴补正略》等，但没有文集传世，该志收录其所撰《张茂仁传》（卷八）[O9]。

4. **补钱大昕集之缺**：清代学者钱大昕虽已有全集整理出版并辑补遗文，但失收仍多。该志收其《募修圆元道院疏引》（卷八）、《浙江分巡宁绍台海防兵备道印宪曾墓志铭》、《国学生陈国祥墓志铭》（卷十五）、《过家江邨旧居》诗（卷十一），“皆为其诗文集所得读者留意”[O9]。

### 三、使用局限

现有证据中，**未发现对《安亭志》使用局限的直接、明确记载**。O9仅从正面肯定其价值，未提及局限；O12亦未涉及局限问题。不能凭常识推断其局限。

- O10所记为1990年上海社会科学院出版社出版的《安亭志》（上海市嘉定县安亭镇修志领导小组编，陆成基主编），属当代新编镇志，其体例为建置、地理、党政群团等十七类，与清嘉庆《安亭志》20卷体例完全不同。两者不可混同。本问题所问应明确指向清嘉庆《安亭志》。
