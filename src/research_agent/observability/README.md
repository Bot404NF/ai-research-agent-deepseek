# 最小本地运行诊断

`runtime.py`在问答和研究节点内记录请求ID、阶段耗时、状态、逻辑模型次数及服务端实际usage。文件位于资料目录同级的`telemetry/日期.jsonl`，已排除Git；`TELEMETRY_ENABLED=false`可关闭。日志不包含输入、输出、完整对话、工具参数、密钥或完整连接地址。

调用数为逻辑invoke/stream次数，不冒充HTTP尝试次数；自动重试实际次数记录为未知。无usage时为null，不按零计费。费用由有官方单价来源的独立评测账本估算，不在业务日志里按Flash价格猜测其他模型费用。

日志写入失败不影响业务；阶段为包含关系，不能直接相加当作总耗时。没有集中监控、自动上传或自动删除历史日志；不把本地诊断说成生产监控平台。
