# 性能验证

第四周入口为`PYTHONPATH=src`下的`python scripts/benchmark.py --output 新路径`；默认只校验，加`--run`才执行统一100题真实业务配对及一次首次调用。记录首内容、正文结束、轮次完成的P50/P95、失败/截断、实际usage与官方单价估算费用。失败不混入成功延迟，但保留在质量和失败分母。

`tests/unit/test_performance.py`验证预算预留、中断后费用保留、本地追问不调用模型、唯一检索入口及采用门槛。`eval/review_week4.py`负责共享预算的逐题AI审核，`eval/smoke_week4.py`负责隔离CLI/HTTP多轮/研究冒烟；均不操作个人会话或重建索引。输出拒绝覆盖，重新运行会重复计费，无自动续跑。

本轮为单用户顺序运行；不证明并发吞吐、浏览器渲染或完整进程冷启动性能，也不把完整研究流程冒烟当作研究性能验收。实际口径、采用条件及费用上限见[第四周方案](../../eval/experiments/week4.md)。
